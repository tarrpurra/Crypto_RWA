# AI + Data Analytics Service

## Purpose

This folder contains the working documentation for the AI + Data Analytics service in AIxRWA.

## Ownership Scope

- allocation engine
- AI reasoning and prompt logic
- Pyth / Hermes ingestion
- quote sampling and market normalization
- risk scoring
- simulations and backtests
- analytics APIs consumed by the website

- [ImplementationPlan.md](./ImplementationPlan.md)

- start with `setup.md` to prepare the service environment
- use `ImplementationPlan.md` as the build and delivery guide
- update `Changes.md` whenever scope, APIs, risk logic, or analytics behavior changes
